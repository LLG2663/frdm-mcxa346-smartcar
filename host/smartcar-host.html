    — 车 → 页面 —

    车是边推算位置边走的：车上没有位置传感器，只有陀螺仪的航向， 所以位置靠航向 + 编码器累计里程推出来，走得越远累积误差越大， 分段停走就是为此兜底（每段都重新对齐航向），默认用它。
    链路失联急停靠"多久没收到字节"判断，桥在串口开着时会一直发心跳， 所以别让页面的标签页休眠太久（休眠会掐掉轮询，但心跳是桥自己在发的，不受影响）。

    串口下发

    ⚠ 这一栏是浏览器直接抓串口，和上面的本机服务抢同一个 COM 口： 同一时刻只能有一个开着。桥已经能下发轨迹，这里留着当兜底和手动调试用。

    将要发送的字节（0 B）：

    B / ms

    分块 + 间隔是为了不把单片机的接收缓冲冲掉；38400 波特率下 32 B/3 ms 约等于把链路跑满。
